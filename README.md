## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Tweak Browser** | Browse all TweakXL records loaded by your installed mods |
| **Conflict Detector** | Flag records modified by more than one installed TweakXL mod |
| **Value Inspector** | Compare original and overridden values for any tweak record |
| **Mod Attribution** | See which mod is responsible for each active tweak record |
